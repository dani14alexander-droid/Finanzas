Servicio temporalmente inactivo

No pudimos conectar con tus datos

Es posible que Supabase haya pausado el proyecto por inactividad. Tus movimientos permanecen guardados y no se eliminaron.

No agregues ni edites movimientos hasta que la base de datos vuelva a estar activa.

Como reactivar la aplicacion

  1. Abre el panel de Supabase e inicia sesion.
  2. Selecciona el proyecto Finanzas.
  3. Presiona Resume project.
  4. Espera a que Supabase indique que el proyecto esta activo.
  5. Regresa a esta pagina y presiona Intentar nuevamente.
Abrir Supabase Intentar nuevamente

Si el proyecto ya esta activo, espera unos minutos. Si el problema continua, revisa que la variable DATABASE_URL del hosting sea correcta.
